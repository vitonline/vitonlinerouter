# Model test samples

`transcription-probe.wav` is synthesized speech saying “Hello, this is a speech recognition test.” Generated locally with Windows System.Speech; contains no user recording. STT probes require recognition of a phrase keyword, rather than accepting arbitrary nonempty output.

`vision-probe.png` is a locally generated solid red 32 by 32 image. Vision probes require an answer identifying red.

These small smoke tests check basic behavior, not transcription accuracy or general vision quality.
